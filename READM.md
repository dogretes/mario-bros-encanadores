# 🍄 Mario Bros Encanadores

Landing page responsiva desenvolvida como projeto de estudo em Front-End, simulando o site de uma empresa de serviços hidráulicos e desentupimento.

O projeto foi desenvolvido com foco em estruturação semântica, estilização com CSS, responsividade e interações utilizando JavaScript.

## 🚀 Demonstração

O projeto apresenta uma página inicial com:

- Apresentação dos serviços
- Navegação entre as seções
- Formulário de contato
- Botão de contato pelo WhatsApp
- Vídeo de fundo
- Interface responsiva para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## 📌 Funcionalidades

### Página inicial
Apresentação da empresa fictícia e chamada para contato.

### Serviços
Seção com os principais serviços oferecidos:

- Desentupimento
- Vazamentos
- Manutenção hidráulica

### Formulário de contato
Formulário interativo desenvolvido com HTML, CSS e JavaScript, incluindo:

- Abertura e fechamento do formulário
- Máscara sobre a página
- Fechamento pelo botão "X"
- Fechamento ao clicar fora do formulário
- Fechamento pela tecla `Esc`
- Validação dos campos
- Simulação do envio do orçamento

### WhatsApp
Botão de acesso direto ao contato pelo WhatsApp.

### Responsividade
O layout foi adaptado para diferentes tamanhos de tela utilizando CSS Media Queries.
